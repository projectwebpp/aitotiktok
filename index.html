การตั้งค่า TikTok API

Client Key จาก TikTok Developer Portal (จำเป็นสำหรับการโพสต์)

Client Secret จาก TikTok Developer Portal

ขั้นตอนการตั้งค่า TikTok API

  1. ไปที่ TikTok Developer Portal
  2. สร้างแอปพลิเคชันและขอสิทธิ์ video.upload
  3. คัดลอก Client Key และ Client Secret มาใส่ในช่องด้านบน
  4. คลิกปุ่ม "เชื่อมต่อ TikTok API" ในแท็บสร้างคลิป
  5. เริ่มสร้างและโพสต์วิดีโอได้ทันที!

เชื่อมต่อบัญชี TikTok

เชื่อมต่อกับ TikTok API

ระบบจะขอสิทธิ์การโพสต์วิดีโอไปยังบัญชี TikTok ของคุณ

วิธีที่ 1: เชื่อมต่อผ่าน OAuth (แนะนำ)

ใช้การยืนยันตัวตนอย่างปลอดภัยผ่าน TikTok OAuth 2.0

วิธีที่ 2: ใช้ Access Token โดยตรง

ได้จาก TikTok Developer Portal หลังจากให้สิทธิ์แอปแล้ว

ระบบจะเก็บข้อมูล Access Token ไว้ใน Firebase Database อย่างปลอดภัย

กำลังเชื่อมต่อกับ TikTok

กำลังนำคุณไปยังหน้าล็อกอินของ TikTok...

ระบบจะขอสิทธิ์ "video.upload" สำหรับการโพสต์คลิป

ไม่มีการเก็บข้อมูลส่วนตัวอื่นๆ นอกเหนือจาก Access Token

ล็อกอินด้วย TikTok

ล็อกอินด้วยบัญชี TikTok

ระบบจะขอสิทธิ์การโพสต์วิดีโอไปยังบัญชี TikTok ของคุณ

ล็อกอินด้วย 4 วิธี

เลือกวิธีล็อกอินที่ต้องการ

วิธีการได้ Access Token
  1. ไปที่ TikTok Developer Portal
  2. สร้างแอปพลิเคชันใหม่
  3. ขอสิทธิ์ "video.upload" และ "user.info.basic"
  4. กดปุ่ม "Authorize" เพื่อรับ Access Token
  5. คัดลอก Access Token มาใส่ในระบบ

สแกน QR Code ด้วยแอป TikTok

เปิดแอป TikTok บนมือถือแล้วสแกน QR Code นี้

QR Code จะหมดอายุใน: 60 วินาที

สแกนด้วยแอป TikTok: ไปที่ Discover → สัญลักษณ์สแกน

เปิดแอป TikTok แล้วแตะไอคอน Scan (หรือ Discover) เพื่อสแกน QR Code
